Ensure the BOOT.bin file is in the root of the SD card.

This will program the PS and the PL together.

The machine itself only reads files named "RUN.G" (i.e. the gcode file you want to run).

Please make sure the file you want to draw is named exactly that way, no "." extensions after that.

Drag your desired ".gcode" into the root of the SD card, and rename it to "RUN.G".

Then plug the SDS card into the Zedboard (before turning it on), turn the on switch. once the LEDs glow, the machine is ready to operate.

And after pressing start, the machine will plot your desired drawing.


(note: after the initial programming on boot, you CAN hot swap the SD card without worry.)


*The default RUN.G is the mariokart.gcode. the directory "ready for demo" includes more demo files for you to run.
